\begin{abstract}
The rapid proliferation of autonomous multi-turn agentic workflows has exacerbated the memory capacity bottleneck in Large Language Model (LLM) inference accelerators. In modern agentic sequences spanning $32\text{k}$ to $128\text{k}+$ tokens ($L=64, H_{\text{kv}}=8, d_k=128$, \texttt{float16}), Key-Value (KV) cache memory footprints expand to $17.18\text{ GB}$ ($16.00\text{ GiB}$) per active $64\text{k}$-token agent stream ($8.59\text{ GB}$ / $8.00\text{ GiB}$ at $32\text{k}$ tokens). Even under multi-chip tensor-parallel weight and KV-cache sharding or $32\text{k}\text{--}64\text{k}$ context distributions, this memory demand precipitates an acute capacity cliff on accelerators such as the Google Cloud TPU v6e Trillium (32~GB HBM per chip), exhausting non-weight HBM capacity after only 3 to 8 concurrent sequences. Existing virtualized inference engines (e.g., PagedAttention / vLLM and SGLang / RadixAttention) mitigate Out-Of-Memory exceptions via reactive demand paging to Host DRAM over PCIe/CXL. However, servicing a synchronous full-layer demand page fault ($64 \times 64\text{ KiB} = 4\text{ MiB}$ across $L=64$ layers, or $1.87\,\mu\text{s}$ of raw wire serialization per single-layer $64\text{ KiB}$ block at $35\text{ GB/s}$ effective PCIe Gen5 bandwidth plus descriptor ring wakeup and dirty writeback) incurs severe pipeline stalls ($0.12\text{ ms}$ to $0.50\text{ ms}$ per faulted step against $0.16\text{ ms}$ ideal compute), causing matrix execution units to idle for 40\% to 70\% of execution time. Furthermore, classical page eviction policies (LRU/LFU) are attention-blind: they inadvertently evict initial prompt attention sinks and active tool schemas while preserving ephemeral chain-of-thought scratchpad tokens.

To overcome these constraints, we present \textbf{Speculative Epistemic KV-Cache Paging (SE-Paging)} governed by the \textbf{Epistemic Least-Likely-Attended (ELLA)} eviction protocol. SE-Paging couples the agent's semantic execution graph and turn-smoothed epistemic branch entropy $\mathcal{H}_i(t)$ to physical memory management: (1) an Epistemic Working Set Estimator (EWSE) projects future attention mass $\mathcal{A}(P_k, t)$, permanently pinning attention sinks and retaining active/idle tool schemas and DAG-boosted history while decaying idle tool schemas below DAG-predicted history within $\approx 8$ steps ($\approx 1$ turn) and aggressively evicting resolved scratchpad pages; (2) an Asynchronous DMA Speculative Prefetcher (ADSP) with sealed-page write-through host mirroring overlaps Host-to-Device page transfers with active matrix computation across a $\tau_{\text{lookahead}}=2$-step horizon; and (3) ELLA establishes bounded competitive ratios relative to offline Belady MIN under both non-cascading trace-regular greedy eviction and randomized Predictive Marker phases. We evaluate SE-Paging in a downscaled $1:32$ trace-driven CPU-based physical tensor-buffer memory-hierarchy emulator (modeling a 2-layer $128\text{ KiB}$ slice per $B=16$-token page, $N_{\text{dev}}=96$ HBM pages [$12.00\text{ MiB}$], $N_{\text{host}}=2{,}500$ DRAM pages [$312.50\text{ MiB}$], and $976$ allocated physical pages [$16$ shared prefix + $48$ private pages/stream, or $15{,}616$ total tokens] across $K=20$ streams) parameterized to scaled TPU v6e Trillium and PCIe Gen5 timing, complemented by a 6-turn live trace replay on Google Cloud Vertex AI (\texttt{gemini-2.5-flash}) and multi-turn SWE-bench and Gorilla API trace evaluations. Across $5{,}940$ logical page-lookup cycles ($11{,}880$ two-stage physical page transactions per protocol) spanning $K \in \{4, 8, 12, 16, 20\}$ concurrent agent streams under $10.17\times$ physical ($13.33\times$ unshared logical) working-set overflow, SE-Paging elevates cache hit rate at $K=20$ from 0.20\% (LRU) and 1.21\% (LFU) to \textbf{28.23\%} ($28.31 \pm 0.38\%$ 5-seed mean), retains \textbf{98.64\%} empirical Query-Key (QK) RoPE dot-product attention mass, eliminates 46.8\% of memory pipeline stall overhead, and increases simulated device throughput by 49.3\% (+53.4\% in host wall-clock page-lookup throughput) over LRU.
\end{abstract}

\section{Introduction}
\IEEEPARstart{E}{nterprise} deployment of autonomous agent swarms built on foundation models (e.g., Gemini 2.5 Pro/Flash, Gemma 2, and Claude) represents a major workload shift in cloud computing. In frameworks such as the Google Agent Development Kit (ADK) and Vertex AI Agent Builder, agents engage in prolonged, multi-turn reasoning workflows involving hierarchical sub-goal decomposition, external tool invocations via OpenAPI schemas~\cite{patil2024gorilla}, and structured artifact generation~\cite{zheng2024sglang, gao2024cachedattention}.

\subsection{The KV-Cache HBM Capacity Cliff}
Unlike traditional stateless NLP classification or single-turn dialogue, agentic sequences accumulate extensive conversational histories, tool schemas, and chain-of-thought scratchpads, routinely expanding context lengths from $32\text{k}$ to $128\text{k}+$ tokens~\cite{kwon2023efficient, xiao2023efficient}.

During auto-regressive transformer decoding, Key and Value activation vectors for every past token must remain memory-resident to avoid redundant quadratic recomputation. The physical memory required scales linearly with context length $S$, transformer layers $L$, KV heads $H_{\text{kv}}$, and head dimension $d_k$:
\begin{equation}
\label{eq:kv_footprint}
\text{Memory}_{\text{KV}} = 2 \times L \times H_{\text{kv}} \times d_k \times S \times \text{bytes\_per\_elem}
\end{equation}
For a representative enterprise model ($L=64$, $H_{\text{kv}}=8$, $d_k=128$, \texttt{float16} with $\text{bytes\_per\_elem}=2$), a sequence of $S = 64\text{k} = 65{,}536$ tokens requires $17{,}179{,}869{,}184\text{ bytes} \approx \mathbf{17.18\text{ GB}}$ decimal ($\mathbf{16.00\text{ GiB}}$ binary) of dedicated High-Bandwidth Memory (HBM) (or $8{,}589{,}934{,}592\text{ bytes} \approx \mathbf{8.59\text{ GB}}$ decimal / $\mathbf{8.00\text{ GiB}}$ binary for $S = 32\text{k} = 32{,}768$ tokens).

On modern cloud accelerators such as the Google Cloud TPU v6e Trillium (configured with 32~GB HBM in 256-chip 2D torus pods, following Google's custom TPU architectures~\cite{jouppi2023tpu}) or GPU nodes~\cite{sheng2023flexgen}, this memory demand triggers an immediate \textit{capacity cliff}: even under multi-chip tensor-parallel model-weight and KV-cache sharding (where 64-layer weights are partitioned across chips, leaving $12\text{--}24\text{ GiB}$ of non-weight HBM per chip) or $32\text{k}\text{--}64\text{k}$ context distributions with shared prefixes, a chip exhausts its remaining HBM pool after serving only 3 to 8 concurrent agent sequences, capping cluster concurrency.

\subsection{The Demand Paging Pipeline Stall Dilemma}
To prevent fatal Out-Of-Memory (OOM) aborts, modern serving runtimes (e.g., vLLM / PagedAttention~\cite{kwon2023efficient} and SGLang~\cite{zheng2024sglang}) partition the KV-cache into discrete non-contiguous physical pages ($B = 16$ tokens per block) and implement reactive \textit{demand swapping} to Host DRAM over PCIe Gen5 or CXL, while multi-turn offloading systems such as CachedAttention~\cite{gao2024cachedattention} perform coarse-grained inter-turn session pre-loading across conversation boundaries.

However, intra-turn demand swapping is fundamentally reactive: when the accelerator's matrix execution units encounter an unmapped page during token generation, the decoding pipeline stalls. Over a PCIe Gen5 $\times 16$ interconnect ($64\text{ GB/s}$ theoretical unidirectional bandwidth, $\approx 35\text{ GB/s}$ effective under multi-stream contention), transferring a single-layer $64\text{ KiB}$ page block ($B=16, H_{\text{kv}}=8, d_k=128$) requires $\approx 1.87\,\mu\text{s}$ of raw wire serialization ($3.74\,\mu\text{s}$ per fused 2-layer $128\text{ KiB}$ slice, or $119.7\,\mu\text{s}$ across all $L = 64$ transformer layers totaling $4\text{ MiB}$ per 16-token block); combined with PCIe DMA descriptor ring wakeup and synchronous dirty-page writeback, a full-model page fault stalls token generation for \textbf{$0.12\text{ ms}$ to $0.50\text{ ms}$} ($0.288\text{--}0.384\text{ ms}$ in our calibrated parameterization vs.\ $0.160\text{ ms}$ ideal 64-layer compute)~\cite{sheng2023flexgen, lee2024infinigen}. Under high sequence concurrency, these synchronous demand stalls accumulate, causing matrix execution units to spend \textbf{40\% to 70\% of wall-clock time stalled waiting on memory}.

\subsection{The Attention-Blind Eviction Failure}
Furthermore, classical operating system page eviction policies (Least Recently Used [LRU], Least Frequently Used [LFU], FIFO) and existing token-pruning or single-step rehearsal heuristics are mismatched with multi-turn agentic transformer physics:
\begin{enumerate}
    \item \textbf{Destruction of Attention Sinks and Tool Schemas:} Transformers concentrate massive attention mass on the initial 1 to 4 sink blocks~\cite{xiao2023efficient} and active OpenAPI tool definitions~\cite{patil2024gorilla}. Under LRU, as an agent generates thousands of intermediate reasoning tokens, initial prompt tokens and tool schemas are aged out to Host RAM. While static window methods like StreamingLLM~\cite{xiao2023efficient} drop middle tokens permanently, Heavy-Hitter Oracle (H2O)~\cite{zhang2023h2o} tracks cumulative attention scores, Quest~\cite{tang2024quest} estimates page criticality from query-key bounding boxes within the current layer without multi-step DMA prefetching, and InfiniGen~\cite{lee2024infinigen} performs single-step layer-adjacent rehearsal prefetching (using skewed query-key projections in layer $l-1$ to prefetch layer $l$), none of these approaches satisfy multi-step PCIe lookahead horizons ($\tau_{\text{lookahead}} = 2$ steps ahead) during abrupt multi-turn agentic tool-call DAG transitions where an entire dormant tool schema or prior history segment suddenly regains high query-key attention alignment. Similarly, unlike purely static agentic workflow prefetchers (KVFlow~\cite{pan2025kvflow}) or prefix-tree LRU schedulers (SGLang / RadixAttention~\cite{zheng2024sglang}) that ignore live generation uncertainty, SE-Paging couples workflow DAG lookahead with turn-smoothed epistemic Shannon entropy $\mathcal{H}_i(t)$.
    \item \textbf{Scratchpad Memory Pollution:} Intermediate chain-of-thought scratchpad tokens are predominantly transient: once an agent concludes a reasoning sub-step, its scratchpad tokens carry rapidly decaying query-key weight unless backtracking occurs. Classical LRU retains newly written scratchpad pages in fast HBM, displacing reusable history and tool schemas.
\end{enumerate}

\subsection{Contributions}
In this paper, we propose \textbf{Hardware-Aware Speculative KV-Cache Paging (SE-Paging)} governed by the \textbf{Epistemic Least-Likely-Attended (ELLA)} eviction protocol. Our key contributions are:
\begin{enumerate}
    \item \textbf{Epistemic Working Set Estimator (EWSE):} A formal priority formulation that projects future page attention mass $\mathcal{A}(P_k, t)$ from agent semantic segment tags, stream-indexed tool-call and history DAG lookahead $\hat{d}_{\text{DAG},i}(P_k, t)^{-1}$, and conditionally re-normalized action-delimiter epistemic Shannon entropy $\mathcal{H}_i(t)$.
    \item \textbf{Asynchronous DMA Speculative Prefetcher (ADSP):} A non-blocking prefetcher restricted to lookahead-predicted non-resident candidates with sealed-page write-through host mirroring that dispatches Host-to-Device transfers at step $n - \tau_{\text{lookahead}}$, overlapping PCIe/CXL transfer latency with matrix compute while eliminating synchronous dirty-page writebacks.
    \item \textbf{Theoretical Performance Guarantees:}
    \begin{itemize}
        \item \textbf{Theorem 1 (Queued Zero-Stall Pipeline Overlap):} Establishes the step-indexed multi-page lookahead condition $\tau_{\text{lookahead}} \ge \left\lceil \frac{M_{\text{pre}}(n) T_{\text{DMA}}(P_k)}{(1-\rho_{\text{bus}})T_{\text{compute}}} \right\rceil$ under an unbacklogged or steady-state stable DMA queue under which device stall cycles are identically zero.
        \item \textbf{Theorem 2 (Attention Mass Preservation):} Proves that ELLA scratchpad eviction beyond the pinned active window ($\delta = 64$ tokens) of the executing stream analytically bounds attention mass loss by $\epsilon_{\text{attn}} \le C\delta^{1-\gamma}\!\left(\frac{1}{\delta} + \frac{1}{\gamma-1}\right) \le \frac{C_{\text{scratch}}}{(\gamma - 1)\delta^{\gamma - 1}}$ ($\le 0.0261$ at $\delta=64$ and $\le 0.0105$ at $\delta=256$ from the intermediate integral bound), complemented by non-circular empirical Query-Key (QK) RoPE softmax attention evaluation showing $98.64\%$ retained attention mass ($96.80\%$ top-$k$ QK page recall).
        \item \textbf{Theorem 3 (Bounded Competitive Ratio):} Uses the competitive caching with predictions framework~\cite{lykouris2021competitive} on acyclic agentic execution graphs to establish expected competitive ratios of $\mathbb{E}[\mathcal{C}_{\text{ELLA}}^{\text{greedy}}] \le 1 + \mathcal{O}(\eta_{\text{tot}}/\text{OPT} + \mathcal{H}_{\max})$ under non-cascading trace-regular greedy eviction and $\mathbb{E}[\mathcal{C}_{\text{ELLA}}^{\text{marker}}] \le 2 + \mathcal{O}(\min(\sqrt{\mathbb{E}[\eta_{\ell_1}]/\text{OPT}}, \log N_{\text{dev}}))$ when paired with randomized Predictive Marker phases relative to offline Belady MIN~\cite{belady1966study}.
    \end{itemize}
    \item \textbf{Downscaled Physical Tensor-Buffer Emulator, Multi-Turn Benchmark Generalization \& Live Vertex AI Trace Replay:} We evaluate SE-Paging in a downscaled $1:32$ CPU-based physical tensor-buffer emulator (modeling a 2-layer $128\text{ KiB}$ slice per page, $N_{\text{dev}}=96$ HBM pages [$12.00\text{ MiB}$], $N_{\text{host}}=2{,}500$ DRAM pages [$312.50\text{ MiB}$], and $976$ allocated physical pages [$16$ shared prefix + $48$ private pages/stream, or $15{,}616$ total tokens] across $K=20$ streams) across $5{,}940$ logical page-lookup cycles ($11{,}880$ two-stage physical page transactions per protocol), comparing against 10 baseline and ablation configurations (\texttt{DEMAND\_LRU}, \texttt{DEMAND\_LFU}, \texttt{SGLang/RadixAttention}~\cite{zheng2024sglang}, \texttt{StreamingLLM}~\cite{xiao2023efficient}, \texttt{H2O}~\cite{zhang2023h2o}, \texttt{Quest}~\cite{tang2024quest}, \texttt{CachedAttention}~\cite{gao2024cachedattention}, \texttt{InfiniGen}~\cite{lee2024infinigen}, \texttt{DEMAND\_ELLA}, and \texttt{STATIC\_DAG\_ELLA}~\cite{pan2025kvflow}), plus a $\pm 50\%$ hyperparameter sensitivity study, multi-turn SWE-bench~\cite{jimenez2024swebench} and Gorilla~\cite{patil2024gorilla} workload traces, and a 6-turn live Google Cloud Vertex AI (\texttt{gemini-2.5-flash}) trace replay.
\end{enumerate}

\section{Related Work}
\begin{itemize}
    \item \textbf{Virtualized KV-Cache and Offloading Systems:} PagedAttention / vLLM~\cite{kwon2023efficient} introduced OS-inspired block-level KV-cache virtualization ($B=16$ tokens) with reactive demand swapping, while SGLang~\cite{zheng2024sglang} introduced RadixAttention for shared prefix-tree reuse with LRU leaf eviction. FlexGen~\cite{sheng2023flexgen} formulated static linear-programming offload schedules across GPU, CPU DRAM, and disk for offline batch throughput, and CachedAttention~\cite{gao2024cachedattention} overlapped inter-turn session restoration across multi-turn conversation boundaries. However, none of these systems prevent intra-turn page-fault stalls when an active agent dynamically switches between tool schemas and history blocks across sub-steps.
    \item \textbf{Token Pruning and Intra-Layer Sparse Attention:} StreamingLLM~\cite{xiao2023efficient} retains initial attention sinks plus a static sliding window while permanently discarding middle tokens. H2O~\cite{zhang2023h2o} evicts tokens with low cumulative attention scores, Quest~\cite{tang2024quest} selects top-$k$ pages per layer using query-key bounding boxes without asynchronous Host-to-Device DMA lookahead, and InfiniGen~\cite{lee2024infinigen} prefetches KV entries from layer $l-1$ to layer $l$ via skewed projections. While effective for single-step layer overlap, single-layer lookahead ($\tau=1$ layer) is insufficient to hide multi-page PCIe Gen5 transfer latency across multi-turn agentic state transitions.
    \item \textbf{Agent-Aware KV-Cache Management:} Recent agentic serving frameworks such as KVFlow~\cite{pan2025kvflow} and SGLang~\cite{zheng2024sglang} exploit static agentic workflow graphs or radix trees to pre-warm or pin agent prefixes during structured tool-calling workloads~\cite{patil2024gorilla, jimenez2024swebench}. However, static DAG distances are deterministic: when an agent encounters high epistemic branching uncertainty during reasoning or tool error recovery, static schedules either evict active scratchpad context prematurely or fail to adjust history retention dynamically. SE-Paging bridges this gap by combining fine-grained categorical page tagging ($\mathcal{P}_{\text{anchor}}, \mathcal{P}_{\text{tool}}, \mathcal{P}_{\text{active}}, \mathcal{P}_{\text{hist}}, \mathcal{P}_{\text{scratch}}$) and stream-indexed forward DAG distance $\hat{d}_{\text{DAG},i}(P_k, t)^{-1}$ with live turn-smoothed epistemic branch entropy $\mathcal{H}_i(t)$ and sealed-page write-through DMA mirroring.
\end{itemize}

\section{System Architecture and Memory Hierarchy}

\subsection{Heterogeneous Memory Hierarchy Model}
We model an AI inference accelerator node (e.g., Google Cloud TPU v6e Trillium programmed via JAX/Pallas kernels~\cite{bradbury2018jax}) comprising two memory tiers:
\begin{itemize}
    \item \textbf{Tier 0 (Device HBM):} High-bandwidth, capacity-constrained memory directly attached to Matrix Execution Units (MXUs) ($\text{BW}_{\text{HBM}} \ge 1.6\text{ TB/s}$, capacity $C_{\text{HBM}} \in \{32, 64\}\text{ GB}$).
    \item \textbf{Tier 1 (Host DRAM / CXL):} High-capacity system memory connected via PCIe Gen5 / CXL ($\text{BW}_{\text{bus}} \approx 32\text{--}64\text{ GB/s}$, capacity $C_{\text{Host}} \ge 512\text{ GB}$).
\end{itemize}

KV-cache is managed in fixed-size physical page blocks $P_k$ containing $B = 16$ tokens. For a single transformer layer ($H_{\text{kv}}=8, d_k=128$, \texttt{float16}), each page block occupies:
\begin{equation}
\label{eq:page_size}
\begin{aligned}
\text{Size}_{\text{1-layer}}(P_k) &= B \times 2 \times H_{\text{kv}} \times d_k \times 2\text{ bytes} \\
&= 65{,}536\text{ bytes } (64\text{ KiB})
\end{aligned}
\end{equation}
In our multi-layer block allocator (Section 6.1), pairs of adjacent transformer layers are co-allocated into fused $128\text{ KiB}$ ($131{,}072\text{ byte}$) physical transfer units to amortize PCIe DMA descriptor ring overhead while permitting layer-pipelined DMA interleaving and sub-stack preemption across concurrent streams without blocking on a monolithic $4\text{ MiB}$ transfer. In a full 64-layer deployment, the 32 fused 2-layer slices of logical block $P_k$ share a single logical page-table descriptor and priority score $\mathcal{A}(P_k, t)$ equipped with a 32-bit layer-residency bitmap (\texttt{slice\_mask}); if sub-stack preemption interrupts a 64-layer transfer after slice $s < 32$, layers $1\dots 2s$ execute while the remaining slices resume at the head of the DMA queue prior to layer $2s+1$. In our scaled $1:32$ slice emulator (modeling a representative 2-layer $128\text{ KiB}$ slice out of $L=64$ layers), per-slice DMA wire transfer latency $T_{\text{DMA}}(P_k) = 3.74\,\mu\text{s}$, per-slice ideal matrix compute time $T_{\text{compute}}^{\text{ideal}} = 5.00\,\mu\text{s}$, and scaled descriptor wakeup / writeback penalties ($T_{\text{wakeup}} = 4.44\,\mu\text{s}$, $T_{\text{wb}} = 3.00\,\mu\text{s}$) scale uniformly by $1:32$ relative to a full 64-layer step ($T_{\text{DMA}}^{\text{64L}} \approx 119.7\,\mu\text{s}, T_{\text{compute}}^{\text{64L}} = 160.0\,\mu\text{s}$, clean fault $288.0\,\mu\text{s}$, dirty fault $384.0\,\mu\text{s}$), preserving exact dimensionless overlap ratios, page-replacement hit rates, and working-set overflow ratios.

\subsection{Categorical Page Classification and Boundary Resolution}
As tokens are ingested or generated by the orchestrator (e.g., Google ADK or SGLang~\cite{zheng2024sglang}), lightweight structural delimiters (\texttt{<|system|>}, \texttt{<|tool\_schema|>}, \texttt{<|history|>}, \texttt{<|thought|>}) tag each token span in $\mathcal{O}(1)$ time with a persistent underlying structural class ($\mathcal{P}_{\text{anchor}}, \mathcal{P}_{\text{tool}}, \mathcal{P}_{\text{hist}}, \mathcal{P}_{\text{scratch}}$), while dynamically maintaining an active sliding window ($\mathcal{P}_{\text{active}}$):
\begin{enumerate}
    \item \textbf{System Anchor ($\mathcal{P}_{\text{anchor}}$):} System prompts and invariant instructions acting as persistent attention sinks~\cite{xiao2023efficient}.
    \item \textbf{Tool Schema ($\mathcal{P}_{\text{tool}}$):} OpenAPI function declarations and JSON schema contracts.
    \item \textbf{Active Generation Window ($\mathcal{P}_{\text{active}}$):} A temporary sliding-window boost applied to the 4 most recent $B=16$-token blocks ($W_{\text{local}} = 64$ tokens at block-aligned boundaries, or $3B+1=49$ to $64$ tokens when the unsealed tail block is partially populated) of the currently executing stream $S_{i^*(t)}$.
    \item \textbf{Conversation History ($\mathcal{P}_{\text{hist}}$):} Verified multi-turn user queries and committed tool outputs.
    \item \textbf{Intermediate Scratchpad ($\mathcal{P}_{\text{scratch}}$):} Ephemeral chain-of-thought reasoning tokens from completed turns.
\end{enumerate}
\textbf{Dominant-Class Boundary and Non-Demoting Sliding-Window Rule:} Structural delimiter transitions seal the current block by default so ephemeral scratchpad tokens do not pollute higher-tier pages; if contiguous sub-block packing is enabled, any $B=16$-token block straddling two delimiter spans dynamically promotes its persistent class $c(P_k) \in \{\mathcal{P}_{\text{anchor}}, \mathcal{P}_{\text{tool}}, \mathcal{P}_{\text{hist}}, \mathcal{P}_{\text{scratch}}\}$ under the dominance hierarchy $\mathcal{P}_{\text{anchor}} \succ \mathcal{P}_{\text{tool}} \succ \mathcal{P}_{\text{hist}} \succ \mathcal{P}_{\text{scratch}}$ prior to sealing. For the currently executing stream $S_{i^*(t)}$ at step $t$, any page $P_k$ within its 4 most recent blocks ($W_{\text{local}}=64$ tokens, indexed by block age $\Delta t_{\text{win}} \in \{0, 1, 2, 3\}$) is evaluated as $\tilde{\mathcal{A}}_i(P_k, t) = \max(\mathcal{A}_{\text{class}, i}(P_k, t), \mathcal{A}_{\text{active}, i}(P_k, t))$, ensuring that an active tool schema ($\mathbb{I}_{\text{tool},i}=1$, score $5\times 10^8$) or anchor ($10^9$) inside $W_{\text{local}}$ is never demoted to $10^7$, while history and scratchpad pages inside the executing stream's $W_{\text{local}}$ are elevated to $\mathcal{A}_{\text{active}, i}(P_k, t) = 10^7\exp(-\kappa \Delta t_{\text{win}})$ during its attention computation and revert to $\mathcal{A}_{\text{class}, i}(P_k, t)$ when the stream yields or advances past 4 blocks (preventing $K \times 4 = 80$ dormant stream windows from monopolizing the 96-page HBM arena).

\section{The Speculative Epistemic Paging Protocol}

\subsection{Epistemic Attention Scoring Formulation}
\begin{definition}[Projected Attention Score]
Let $t \in \mathbb{N}$ denote the discrete execution / page-lookup step index (where each macroscopic agentic reasoning turn spans $8\text{--}12$ execution steps). For a KV-cache page $P_k$ evaluated for agent stream $S_i$ at step $t$, let $\Delta t_i(P_k, t) = t - t_{\text{last\_access},i}(P_k) \ge 0$ denote the elapsed execution step count since the semantic segment containing $P_k$ was last generated, selected by the router, or accessed by stream $S_i$, and let $\hat{d}_{\text{DAG},i}(P_k, t) \in \mathbb{N} \cup \{\infty\}$ denote the shortest-path forward step distance in stream $S_i$'s workflow DAG from its current node to the next node referencing $P_k$'s segment. Its per-stream class score $\mathcal{A}_{\text{class},i}(P_k, t)$ under ELLA is defined as:
\begin{equation}
\label{eq:ella_score}
\resizebox{0.89\columnwidth}{!}{$\displaystyle
\mathcal{A}_{\text{class},i}(P_k, t) \triangleq \begin{cases}
10^9, & c(P_k) = \mathcal{P}_{\text{anchor}} \\
5\!\times\!10^8\,\mathbb{I}_{\text{tool},i}(P_k, t) + (1\!-\!\mathbb{I}_{\text{tool},i}(P_k, t))\!\left(W_{\text{tool}} e^{-\lambda_{\text{tool}}\Delta t_i(P_k, t)} + C_{\text{floor}}\right), & c(P_k) = \mathcal{P}_{\text{tool}} \\
\max\!\left(C_{\text{hist}}, W_{\text{hist}} e^{-\lambda \Delta t_i(P_k, t)}(1 - \mathcal{H}_i(t) + \epsilon)\right) + B_{\text{DAG}}\mathbb{I}_{\text{DAG},i}(P_k, t) + \eta_{\text{DAG}}\hat{d}_{\text{DAG},i}(P_k, t)^{-1}, & c(P_k) = \mathcal{P}_{\text{hist}} \\
W_{\text{scratch}} \exp(-\mu \Delta t_i(P_k, t))\,\mathcal{H}_i(t) + \eta_{\text{DAG}}\hat{d}_{\text{DAG},i}(P_k, t)^{-1}, & c(P_k) = \mathcal{P}_{\text{scratch}}
\end{cases}$}
\end{equation}
with effective per-stream score $\tilde{\mathcal{A}}_i(P_k, t) = \max(\mathcal{A}_{\text{class},i}(P_k, t), 10^7\exp(-\kappa\Delta t_{\text{win}})\mathbb{I}[P_k \in \mathcal{P}_{\text{active},i} \wedge i = i^*(t)])$, and global shared-page priority across all referencing streams $\mathcal{O}(P_k)$:
\begin{equation}
\label{eq:global_score}
\mathcal{A}(P_k, t) \triangleq \max_{S_i \in \mathcal{O}(P_k)} \tilde{\mathcal{A}}_i(P_k, t)
\end{equation}
where $\mathbb{I}_{\text{tool},i}(P_k, t) = \mathbb{I}[c(P_k)=\mathcal{P}_{\text{tool}} \wedge \hat{d}_{\text{DAG},i}(P_k, t) \le d_{\text{look}}] \in \{0, 1\}$ and $\mathbb{I}_{\text{DAG},i}(P_k, t) = \mathbb{I}[\hat{d}_{\text{DAG},i}(P_k, t) \le d_{\text{look}}] \in \{0, 1\}$ equal $1$ when the orchestrator's workflow DAG or grammar-constrained router predicts a reference to tool schema or history page $P_k$ within lookahead depth $d_{\text{look}} = 2$ steps (and $0$ otherwise); $W_{\text{tool}} = 500$, $W_{\text{hist}} = 600$, and $W_{\text{scratch}} = 100$ are the initial class weights; $C_{\text{floor}} = 200$ and $C_{\text{hist}} = 120$ are the asymptotic tool-schema and verified-history retention floors; $B_{\text{DAG}} = 350.0$ is the history lookahead boost; $\hat{d}_{\text{DAG},i}(P_k, t)^{-1} \in [0, 1]$ is the inverse forward step distance ($0$ if $\hat{d}_{\text{DAG},i}(P_k, t) = \infty$, scaled by $\eta_{\text{DAG}} = 10$); and step-level decay hyperparameters are calibrated on held-out multi-turn traces to $\kappa = 0.05$, $\lambda = 0.08\text{ step}^{-1}$, $\lambda_{\text{tool}} = 0.08\text{ step}^{-1}$, $\mu = 0.45\text{ step}^{-1}$, and $\epsilon = 0.10$ ($\mu \gg \lambda = \lambda_{\text{tool}} > \kappa > 0$). Ties in $\mathcal{A}(P_k, t)$ are broken deterministically by $\hat{d}_{\text{DAG},i}(P_k, t)^{-1}$ (evicting smaller $\hat{d}_{\text{DAG},i}^{-1}$ first during victim selection and admitting larger $\hat{d}_{\text{DAG},i}^{-1}$ first during prefetching), then round-robin stream index $i$, oldest LRU timestamp $t_{\text{last\_access},i}(P_k)$, and finally lowest physical page index $k$.
\end{definition}

\textbf{Idle Tool-Schema Decay Horizon vs.\ DAG-Boosted History Preemption:} Under Eq.~\eqref{eq:ella_score}, a newly used tool schema entering the idle state ($\mathbb{I}_{\text{tool},i}(P_k, t) = 0$ at $\Delta t_i = 0$) has score $W_{\text{tool}} + C_{\text{floor}} = 500 + 200 = 700$, protecting it against immediate eviction during the current turn. Once dormant for $\Delta t_i > \ln(500/270)/0.08 \approx 7.70\text{ steps}$ ($\approx 1$ turn at $8\text{--}12$ steps/turn), its priority drops below $470$ (reaching $300.9$ by $\Delta t_i = 20$ steps), enabling a floored DAG-predicted history page ($\ge C_{\text{hist}} + B_{\text{DAG}} = 120 + 350 = 470$, or $480$ at $\hat{d}_{\text{DAG},i} = 1$) to preempt dormant tool schemas when resuming an earlier conversation branch. Meanwhile, because $t_{\text{last\_access},i}(P_k)$ and $\hat{d}_{\text{DAG},i}(P_k, t)$ are maintained at segment-to-page table granularity by the orchestrator, scoring requires $\mathcal{O}(1)$ metadata updates per page without materializing quadratic attention matrices inside fused Pallas FlashAttention-2 kernels~\cite{dao2024flashattention2}.

\textbf{Action-Delimiter Epistemic Entropy $\mathcal{H}_i(t)$:} To prevent deterministic JSON punctuation and syntax tokens from driving entropy artificially toward zero, the orchestrator evaluates Shannon entropy exclusively at structural branch and action delimiters $m \in \mathcal{T}_{\text{branch}}$ (e.g., \texttt{<|thought|>}, \texttt{<|tool\_call|>}, and tool-name selection tokens) over the top-$64$ grammar-valid candidate action-token subset $\mathcal{V}_{\text{act}}$ ($|\mathcal{V}_{\text{act}}| = 64$, or top-$K_{\text{log}}$ returned logprobs on commercial APIs). Raw token probabilities are conditionally re-normalized over $\mathcal{V}_{\text{act}}$ via $\tilde{p}_{i,m}(v) = p_{i,m}(v) / \sum_{u \in \mathcal{V}_{\text{act}}} p_{i,m}(u)$ so that $\sum_{v \in \mathcal{V}_{\text{act}}} \tilde{p}_{i,m}(v) = 1$, and smoothed from neutral prior $\mathcal{H}_i(0) = 0.50$ via an exponential moving average with factor $\beta = 0.30$:
\begin{equation}
\label{eq:branch_entropy}
\begin{aligned}
\mathcal{H}_i(t) &= (1 - \beta)\mathcal{H}_i(t-1) \\
&\quad + \beta\!\left(-\frac{1}{\ln |\mathcal{V}_{\text{act}}|} \sum_{v \in \mathcal{V}_{\text{act}}} \tilde{p}_{i,m}(v)\ln \tilde{p}_{i,m}(v)\right) \in [0, 1]
\end{aligned}
\end{equation}
with $0\ln 0 \triangleq 0$. While strict asymptotic floor separation ($W_{\text{scratch}} + \eta_{\text{DAG}} = 110 < C_{\text{hist}} = 120 < C_{\text{floor}} = 200$) guarantees that neither dormant tool schemas nor verified history ever decay below unwindowed scratchpad pages as $\Delta t_i \to \infty$, modulating $\mathcal{H}_i(t) \in [0, 1]$ drives two critical dynamic ordering mechanisms: (1) \textit{intra-tier history crossover}, where high branch uncertainty ($\mathcal{H}_i(t) \to 1$) rapidly anneals unpredicted recent history pages $W_{\text{hist}}e^{-\lambda \Delta t_i}(1 - \mathcal{H}_i(t) + \epsilon)$ toward $C_{\text{hist}} = 120$, allowing older DAG-boosted history pages ($\ge 470$) to outrank recent turns during exploratory backtracking; and (2) \textit{cross-stream scratchpad arbitration}, where across concurrent streams $S_i \ne S_j$, stream $S_i$ in high-uncertainty exploration ($\mathcal{H}_i(t) \to 1$) retains higher scratchpad priority than stream $S_j$ whose branching has resolved ($\mathcal{H}_j(t) \to 0$ via geometric EMA decay $(1-\beta)=0.7$ per delimiter, where scratchpad priority decays toward $\le 10$, i.e., $\eta_{\text{DAG}}\hat{d}_{\text{DAG},i}(P_k, t)^{-1}$).

\subsection{Epistemic Least-Likely-Attended (ELLA) Eviction Invariant}
\begin{invariant}[ELLA Evictable Victim Selection]
Let $\tau_{\text{lookahead}} = 2$ steps denote the speculative lookahead horizon and let $M_{\text{pre}}^{\max} = 4$ pages/step denote the global batch prefetch cap (Section 5.1). Let $\text{Resident}_{\text{evictable}}(\text{HBM}) \triangleq \text{Resident}_{\text{clean}}(\text{HBM}) \setminus (\mathcal{P}_{\text{anchor}} \cup \mathcal{P}_{\text{pinned\_prefetch}} \cup \mathcal{P}_{\text{active\_unsealed}})$ denote the subset of HBM-resident sealed pages with completed Host DRAM write-through mirrors excluding system anchor pages ($\mathcal{P}_{\text{anchor}}$, score $10^9$), in-flight/admitted prefetch-pinned pages ($\mathcal{P}_{\text{pinned\_prefetch}}$, bounded by $\le \tau_{\text{lookahead}} M_{\text{pre}}^{\max} = 8$ pages globally), and currently unsealed active tail pages ($\mathcal{P}_{\text{active\_unsealed}}$, $\le K$ pages). When allocating or prefetching a page requires a free frame in Device HBM, the controller evicts:
\begin{equation}
\label{eq:victim_select}
P_{\text{victim}} = \arg\min_{P_j \in \text{Resident}_{\text{evictable}}(\text{HBM})} \mathcal{A}(P_j, t)
\end{equation}
If $\text{Resident}_{\text{evictable}}(\text{HBM}) = \emptyset$ under extreme concurrency, ADSP suppresses speculative prefetch admission and, upon a mandatory synchronous demand fault, releases the lowest-scoring page in $\mathcal{P}_{\text{pinned\_prefetch}}$ prior to ever evicting any $\mathcal{P}_{\text{anchor}}$ page ($10^9$).
\end{invariant}

\subsection{Asynchronous DMA Speculative Prefetcher and Write-Through Mirroring}
To avoid blocking Device-to-Host writebacks during eviction, SE-Paging implements \textbf{Asynchronous Sealed-Page Write-Through Mirroring}: while an active tail page in $\mathcal{P}_{\text{active\_unsealed}}$ ($B=16$ tokens) is populated token-by-token across 16 decoding steps, it remains pinned in HBM; once all 16 token slots are filled and the page is sealed, a single asynchronous background DMA copy mirrors the full $128\text{ KiB}$ ($4\text{ MiB}$ full-stack) clean page to its pre-allocated Host DRAM slot, avoiding $16\times$ partial-page PCIe write amplification. Because KV-cache tokens are append-only in causal transformer decoding, sealed pages are never mutated in-place; $\text{Resident}_{\text{evictable}}(\text{HBM})$ selects clean mirrored frames (\texttt{is\_mirrored\_to\_host == True}) and only awaits an in-flight write-through descriptor if all mirrored frames are exhausted. At step $n - \tau_{\text{lookahead}}$ ($\tau_{\text{lookahead}} = 2$ steps prior to target execution step $n$), ADSP restricts candidate selection to non-resident lookahead-predicted pages ($\mathbb{I}_{\text{tool},i}(P_k, n) = 1$ or $\mathbb{I}_{\text{DAG},i}(P_k, n) = 1$ within $d_{\text{look}} = 2$ steps) across active streams, sorts candidates $P_{\text{cand}, r}$ in descending order of $\mathcal{A}(P_{\text{cand}, r}, n)$ (breaking ties as specified in Definition 1) against evictable HBM victims $P_{\text{victim}, r}$ in ascending order, and dispatches up to $M_{\text{pre}}(n) \le 4$ asynchronous Host-to-Device DMA transfers whenever $\mathcal{A}(P_{\text{cand}, r}, n) > \mathcal{A}(P_{\text{victim}, r}, n)$, pinning admitted pages in $\mathcal{P}_{\text{pinned\_prefetch}}$ (up to $\tau_{\text{lookahead}}M_{\text{pre}}^{\max} = 8$ pages across the 2-step window) until step $n$ completes.

\section{Formal Theoretical Analysis}

\subsection{Theorem 1: Queued Zero-Stall Pipeline Overlap Invariant}
\begin{theorem}[Zero-Stall Overlap Under Queued DMA]
Let $T_{\text{compute}}$ be the per-step execution latency of matrix execution units, let $T_{\text{DMA}}(P_k) = \text{Size}(P_k)/\text{BW}_{\text{bus}}$ be the raw Host-to-Device wire transfer time of page $P_k$ under persistent zero-wakeup DMA descriptor rings, let $M_{\text{pre}}(n) = |\mathcal{W}_{\text{spec}}(n)|$ be the batch prefetch count dispatched at $t_{\text{dispatch}} = t_n - \tau_{\text{lookahead}} T_{\text{compute}}$ for step $n$, and let $\rho_{\text{bus}} \in [0, 1)$ denote background interconnect utilization (absorbing full-duplex write-through mirroring and prior-step traffic under the steady-state queue stability condition $\mathbb{E}[M_{\text{pre}}]T_{\text{DMA}}(P_k)/(1-\rho_{\text{bus}}) \le T_{\text{compute}}$ so the DMA queue is unbacklogged at $t_{\text{dispatch}}$). If the speculative lookahead horizon satisfies:
\begin{equation}
\label{eq:lookahead_cond}
\tau_{\text{lookahead}} \ge \left\lceil \frac{M_{\text{pre}}(n) \cdot T_{\text{DMA}}(P_k)}{(1 - \rho_{\text{bus}}) \cdot T_{\text{compute}}} \right\rceil
\end{equation}
and $M_{\text{pre}}(n)$ clean sealed victim frames in $\text{Resident}_{\text{evictable}}(\text{HBM})$ (disjoint from active working sets over $[t_{\text{dispatch}}, t_n)$) are available in HBM, then step $n$ experiences identically zero memory stall cycles ($\Delta_{\text{stall}}(n) \equiv 0$).
\end{theorem}

\begin{proof}
Under an unbacklogged DMA queue at $t_{\text{dispatch}} = t_n - \tau_{\text{lookahead}} \cdot T_{\text{compute}}$, available bus bandwidth $(1 - \rho_{\text{bus}})\text{BW}_{\text{bus}}$, and write-through clean victim reclamation, the serialized completion time of all $M_{\text{pre}}(n)$ pages is:
\begin{equation}
\label{eq:dma_completion}
t_{\text{completion}} = t_{\text{dispatch}} + \frac{M_{\text{pre}}(n) \cdot T_{\text{DMA}}(P_k)}{1 - \rho_{\text{bus}}}
\end{equation}
Substituting Eq.~\eqref{eq:lookahead_cond} yields $\tau_{\text{lookahead}} \cdot T_{\text{compute}} \ge M_{\text{pre}}(n) T_{\text{DMA}}(P_k) / (1 - \rho_{\text{bus}})$, which implies $t_{\text{completion}} \le t_n$. Thus all $M_{\text{pre}}(n)$ pages are mapped in HBM prior to $t_n$, and $\Delta_{\text{stall}}(n) = \max(0, t_{\text{completion}} - t_n) = 0$. When extreme overcommit ($K=20$, e.g., an isolated burst of $M_{\text{pre}}(n)=4$ where $\lceil 4 \times 3.74 / (0.82 \times 5.0)\rceil = 4 > \tau_{\text{lookahead}}=2$) causes a batch to exceed the 2-step lookahead window, wall-clock stall time is reduced by the overlapped lookahead duration $\tau_{\text{lookahead}} T_{\text{compute}}$ (leaving a residual partial-overlap wait $T_{\text{fault}}^{\text{part}}$, parameterized alongside synchronous driver wakeup $T_{\text{wakeup}}$ on unpredicted demand faults in Section 6.1).
\end{proof}

\subsection{Theorem 2: Attention Mass Bounded Approximation}
\begin{theorem}[Attention Mass Preservation]
Under Rotary Position Embeddings (RoPE~\cite{su2024roformer}) where post-softmax normalized attention weights ($\sum_{j=1}^m \alpha_{m,j} = 1$ across all context tokens) satisfy a power-law decay on completed scratchpad tokens at relative token distance $|m - n| \ge \delta$ as $\alpha_{m,n} \le C |m - n|^{-\gamma}$ ($\gamma > 1$), evicting scratchpad pages outside the executing stream's pinned active window at token distance $\ge \delta = W_{\text{local}}$ under ELLA preserves at least $1 - \epsilon_{\text{attn}}$ of the full-context attention mass, where:
\begin{equation}
\label{eq:attn_bound}
\epsilon_{\text{attn}} \le C\delta^{1-\gamma}\!\left(\frac{1}{\delta} + \frac{1}{\gamma - 1}\right) \le \frac{C_{\text{scratch}}}{(\gamma - 1)\delta^{\gamma - 1}}, \; C_{\text{scratch}} \triangleq C\gamma
\end{equation}
\end{theorem}

\begin{proof}
For the stream $S_{i^*(t)}$ executing step $t$, ELLA permanently retains all $4\ \mathcal{P}_{\text{anchor}}$ pages ($64$ sink tokens) and protects its $4\ \mathcal{P}_{\text{active}, i^*(t)}$ pages ($W_{\text{local}} = 64$ tokens at block-aligned boundaries, $|m-n| < \delta = 64$) in HBM. Because the attention sink and local window tokens alone contribute at least $Z_{\text{pinned}} = \sum_{j \in \text{Tokens}(\mathcal{P}_{\text{anchor}} \cup \mathcal{P}_{\text{active}, i^*(t)})} \exp(q_m^\top k_j / \sqrt{d_k})$ to the softmax partition denominator $Z_m \ge Z_{\text{pinned}}$, evicting distant scratchpad tokens cannot inflate the remaining weights, and under the theorem's calibrated RoPE decay premise the normalized per-token weight on any distant scratchpad token $|m-n| \ge \delta$ satisfies $\alpha_{m,n} \le C|m-n|^{-\gamma}$ with uniformly bounded scale constant $C = 0.25$ and decay exponent $\gamma = 1.65$. Bounding the discrete token sum over individual token indices $j \in \text{Tokens}(\mathcal{P}_{\text{evicted}})$ at distance $x = |m - n| \ge \delta \ge 1$ up to history length $S_{\text{history}} \le S$ via the integral test and relaxing $S_{\text{history}} \to \infty$:
\begin{align}
\label{eq:integral_bound}
\sum_{j \in \text{Tokens}(\mathcal{P}_{\text{evicted}})} \alpha_{m, j} &\le C \delta^{-\gamma} + \int_{\delta}^{S_{\text{history}}} C x^{-\gamma}\,dx \nonumber \\
&\le C \delta^{-\gamma} + \int_{\delta}^{\infty} C x^{-\gamma}\,dx \nonumber \\
&= C\delta^{1-\gamma}\!\left(\frac{1}{\delta} + \frac{1}{\gamma - 1}\right) \le \frac{C\gamma}{(\gamma - 1)\delta^{\gamma - 1}}
\end{align}
since $\frac{1}{\delta} \le 1$ for $\delta \ge 1$. Evaluating the tighter intermediate integral-test expression $C\delta^{1-\gamma}(\frac{1}{\delta} + \frac{1}{\gamma-1})$ in Eqs.~\eqref{eq:attn_bound}--\eqref{eq:integral_bound} at $\delta = W_{\text{local}} = 64$ tokens ($\gamma = 1.65, C = 0.25$) yields the exact analytical bound $\epsilon_{\text{attn}} \le 0.0261$ (and $\epsilon_{\text{attn}} \le 0.0105$ at $\delta = 256$, whereas the looser closed-form right-hand expression evaluates to $0.0425$). Under the analytical distance-only RoPE proxy, evicted scratchpad mass is $6.4 \times 10^{-4}$ ($99.93\%$ retained), while non-circular empirical Query-Key (QK) dot-product softmax attention across all $K=20$ multi-turn traces retains $98.64 \pm 0.18\%$ of full-context attention mass (Section 6.1).
\end{proof}

\subsection{Theorem 3: Bounded Competitive Ratio Under Epistemic Predictions}
\begin{theorem}[Expected Competitive Ratio vs.\ Belady MIN]
On an acyclic agentic execution DAG where ELLA orders pages via Eq.~\eqref{eq:ella_score} using inverse forward DAG distance $\hat{d}_{\text{DAG},i}(P_k, t)^{-1}$ under turn-smoothed branch entropy $\mathcal{H}_i(t) \le \mathcal{H}_{\max}$, let $\eta_{\text{tot}}$ denote the cumulative trace-wide baseline rank-inversion count from finite-decay crossovers across all cache phases, and let $\eta_{\ell_1}$ denote the induced $\ell_1$ next-arrival timestamp prediction error. Then ELLA's expected competitive ratio $\mathbb{E}[\mathcal{C}_{\text{ELLA}}]$ relative to offline Belady MIN~\cite{belady1966study} satisfies:
\begin{equation}
\label{eq:comp_ratio}
\resizebox{0.89\columnwidth}{!}{$\displaystyle
\mathbb{E}[\mathcal{C}_{\text{ELLA}}] \le \begin{cases}
1 + \mathcal{O}\!\left(\dfrac{\eta_{\text{tot}}}{\text{OPT}} + \mathcal{H}_{\max}\right), & \text{deterministic greedy (non-cascading trace regularity, } \mathcal{C}_0 = 1\text{)} \\[6pt]
2 + \mathcal{O}\!\left(\min\!\left(\sqrt{\dfrac{\mathbb{E}[\eta_{\ell_1}]}{\text{OPT}}},\, \log N_{\text{dev}}\right)\right), & \text{paired with randomized Predictive Marker phases (\cite{lykouris2021competitive}, } \mathcal{C}_0 = 2\text{)}
\end{cases}$}
\end{equation}
\end{theorem}

\begin{proof}
Belady MIN~\cite{belady1966study} evicts the resident page whose next access step $t_{\text{next}}(P_k)$ is furthest in the future. In the deterministic limit $\mathcal{H}_i(t) \to 0$, completed unreferenced scratchpad pages ($t_{\text{next}} = \infty$) have score $0$, anchors ($t_{\text{next}} = t+1$) have score $10^9$, and pending tools ($t_{\text{next}} \le t+2$) have score $5 \times 10^8$. Under trace regularity (where future reuse respects the semantic tier hierarchy, intra-tier reuse prior to reaching the asymptotic floors $C_{\text{floor}}, C_{\text{hist}}$ aligns monotonically with recency $\Delta t_i$, and floored reuse follows $\hat{d}_{\text{DAG},i}(P_k, t)^{-1}$), ELLA's eviction ordering is order-isomorphic to $t_{\text{next}}(P_k)$ ($\eta_{\text{tot}} = 0, \mathcal{C}_0 = 1$). When finite-decay crossovers between idle $\mathcal{P}_{\text{tool}}$ and $\mathcal{P}_{\text{hist}}$ occur with cumulative trace-wide rank-inversion count $\eta_{\text{tot}}$ under a non-cascading trace (where each pairwise inversion incurs $\mathcal{O}(1)$ extra misses rather than $\Omega(N_{\text{dev}})$ thrashing loops), they contribute $\mathcal{O}(\eta_{\text{tot}}/\text{OPT})$. Under stochastic branching with a calibrated mode-selecting router ($\arg\max_{v \in \mathcal{V}_{\text{act}}} \tilde{p}_{i,m}(v)$ so top-1 misprediction probability $p_{\text{err}} = 1 - \max_v \tilde{p}_{i,m}(v) \le (\ln |\mathcal{V}_{\text{act}}|/\ln 2) H_{\text{norm}}(\tilde{p}_{i,m})$), bounded pages $B_{\text{node}} = \mathcal{O}(1)$ per DAG decision node, and turn-smoothed branch entropy $\mathcal{H}_i(t) \le \mathcal{H}_{\max}$ (where $\mathcal{H}_i(t) \ge \beta H_{\text{norm}}(\tilde{p}_{i,m})$ via Eq.~\eqref{eq:branch_entropy}), the expected induced rank inversions per decision node are bounded by $\mathcal{O}(\mathcal{H}_{\max})$; summing across $\Theta(\text{OPT})$ phases yields the first bound in Eq.~\eqref{eq:comp_ratio}. Finally, when ELLA's priority ranking drives randomized Predictive Marker phases (resetting mark bits whenever $N_{\text{dev}}$ distinct pages are requested to prevent deterministic thrashing cascades), applying the learning-augmented caching theorem of Lykouris and Vassilvitskii~\cite{lykouris2021competitive} yields the second bound in Eq.~\eqref{eq:comp_ratio}.
\end{proof}

\section{Empirical Evaluation and Benchmark Results}

\subsection{Experimental Methodology and Downscaled 1:32 Physical Tensor Emulator}
Following established LLM serving simulation methodologies such as Vidur~\cite{agrawal2024vidur}, we evaluate multi-tier paging deterministically without nondeterministic network or compiler jitter via a \textbf{downscaled $1:32$ trace-driven CPU-based physical tensor-buffer memory-hierarchy emulator} in Python/NumPy on an Apple Silicon workstation (8 CPU cores, APFS storage), parameterized to scaled TPU v6e Trillium and PCIe Gen5 timing, complemented by a live 6-turn trace replay on Google Cloud Vertex AI (\texttt{gemini-2.5-flash}):
\begin{itemize}

    \begin{equation}
    \label{eq:exact_stall_accounting}
    \resizebox{0.84\columnwidth}{!}{$\displaystyle
    \sum T_{\text{stall}} = N_{\text{miss}}^{\text{dirty}}\!\times\!12.00\,\mu\text{s} + N_{\text{miss}}^{\text{clean}}\!\times\!9.00\,\mu\text{s} + M_{\text{part}}\!\times\!2.50\,\mu\text{s}$}
    \end{equation}

Within each turn ($8\text{--}12$ steps/turn, $\mathcal{H}_i(t) \sim \text{Beta}(2,5)$, tool transitions every $2$ turns), each stream re-references a hot kernel of $\approx 4.5\text{--}4.7$ private pages alongside streaming scratchpad allocations. Table~\ref{tab:paging_telemetry} reports canonical seed-0 hit counts alongside 5-seed $\text{Mean} \pm \text{SD}$ throughput; Table~\ref{tab:ablation_k20} reports 5-seed $\text{Mean} \pm \text{SD}$ across all 11 policy configurations.
    \item \textbf{Transaction Accounting ($N_{\text{tx}} = 11{,}880$ Physical Transactions per Protocol):} Each stream executes $99$ logical page-lookup cycles ($396, 792, 1{,}188, 1{,}584,$ and $1{,}980$ accesses for $K = 4, 8, 12, 16, 20$, summing to $5{,}940$ logical accesses per protocol, or $2 \times 5{,}940 = 11{,}880$ two-stage physical page transactions).
    \item \textbf{Non-Circular Empirical QK Attention Retention \& Adapted Baselines:} \texttt{Sim.\ Dev.\ Ops/s} $= \text{Accesses} / (T_{\text{compute}}^{\text{ideal}} + \sum T_{\text{stall}}) = 200{,}000 / (1 + \text{Stall Ratio}/100)$, while \texttt{Wall Throughput (Ops/s)} $= \text{Accesses} / (T_{\text{compute}}^{\text{ideal}} + \sum T_{\text{stall}} + T_{\text{host\_cp}})$, where $T_{\text{host\_cp}}$ ($1.55\text{--}3.75\,\mu\text{s}$/access) is the measured host Python control-plane, $\mathcal{O}(N_{\text{dev}})$ victim-priority scan, and physical NumPy \texttt{float16} copy time. To avoid circularity with Theorem 2's analytical distance-only RoPE decay curve, Table~\ref{tab:ablation_k20} evaluates two non-circular empirical attention metrics computed directly from scaled dot-product attention $\alpha_{m,j} = \text{softmax}_j(\text{RoPE}(q_m)^\top \text{RoPE}(k_j)/\sqrt{d_k})$ over semantic key embeddings in the tensor arena: \texttt{Emp.\ QK Attn Retained (\%)} ($\sum_{j \in \text{Tokens}(\text{Resident}(\text{HBM}))} \alpha_{m,j}$ prior to fault servicing) and \texttt{Top-$k$ QK Recall (\%)} ($k=8$ highest QK-attention pages resident in HBM). SOTA baselines are parameterized into lossless two-tier $B=16$ block policies: \texttt{SGLang/RadixAttention}~\cite{zheng2024sglang} protects shared prefix interior nodes ($\text{owners} > 1$) and evicts unshared leaf blocks via LRU; \texttt{StreamingLLM}~\cite{xiao2023efficient} pins the $4\ \mathcal{P}_{\text{anchor}}$ and $4\ \mathcal{P}_{\text{active}}$ blocks while evicting middle blocks by oldest block index; \texttt{H2O}~\cite{zhang2023h2o} evicts the non-sink/window block with lowest cumulative QK score; \texttt{Quest}~\cite{tang2024quest} ranks blocks by current-step query-key bounding-box criticality without multi-step DMA lookahead; \texttt{CachedAttention}~\cite{gao2024cachedattention} pre-loads history blocks only at turn boundaries; and \texttt{InfiniGen}~\cite{lee2024infinigen} performs 1-step rehearsal lookahead ($\tau=1$, $M_{\text{pre}} \le 2$).
\end{itemize}

\subsection{Live Multi-Turn Vertex AI (\texttt{gemini-2.5-flash}) Trace Replay}
To validate SE-Paging on authentic LLM agent execution traces beyond synthetic $\text{Beta}(2,5)$ entropy sampling, we executed a 6-turn agentic workflow on Google Cloud Vertex AI (\texttt{project="aniket-personal"}, \texttt{model="gemini-2.5-flash"}) across $6$ reasoning turns (Tool Selection $\to$ Scratchpad Ledger Audit $\to$ SQL Tool Invocation $\to$ History Compliance Synthesis $\to$ Verification Tool Call $\to$ Final Commit, generating $1{,}828$ live tokens with variable turn lengths of $260\text{--}356$ tokens/turn). To evaluate Eq.~\eqref{eq:branch_entropy} under commercial API constraints, we extracted the top-$20$ returned token logprobs (\texttt{response\_logprobs=True, logprobs=20}) at structural action/branch delimiter positions and conditionally re-normalized $\tilde{p}_{i,m}(v)$ over the grammar-valid action candidates. Replaying the resulting variable-length token spans across $K=20$ concurrent streams with cyclic turn-phase offsets produced a distinct schedule of $2{,}140$ page accesses across $976$ allocated physical pages. On this live \texttt{gemini-2.5-flash} trace replay (Table~\ref{tab:generalization_sensitivity}), \texttt{DEMAND\_LRU} and \texttt{DEMAND\_LFU} achieved $3.74\%$ ($80/2{,}140$ hits, $231.03\%$ Stall Ratio) and $7.10\%$ ($152/2{,}140$ hits, $222.95\%$ Stall Ratio), whereas \texttt{DEMAND\_ELLA} reached $29.35\%$ ($628$ hits, $127.18\%$ Stall Ratio) and \texttt{SPECULATIVE\_ELLA} achieved a \textbf{34.21\% hit rate} ($732/2{,}140$ hits, including $74$ completed prefetches and $M_{\text{part}}=31$ partially overlapped misses), reducing Stall Ratio by \textbf{49.6\% relative} ($114.48$ percentage points) to $116.55\%$ and boosting simulated device throughput by \textbf{1.53$\times$} ($92{,}358.82$ vs.\ $60{,}417.84\text{ Ops/s}$).

\subsection{Discussion of Findings and Ablation Analysis}
\begin{enumerate}
    \item \textbf{Hit Rate Resilience, \texttt{DEMAND\_ELLA} vs.\ \texttt{DEMAND\_LFU} at $K=16$, and the $K=20$ LFU Capacity Cliff (Fig.~\ref{fig:paging_plots}):} At $K=16$, \texttt{DEMAND\_LFU} achieves a $51.39\%$ hit rate ($770$ dirty misses, $116.67\%$ Stall Ratio, $92{,}307.69\text{ Sim.\ Dev.\ Ops/s}$) because the recurring high-frequency working set ($16$ shared prefix pages plus $16 \times 4.5 = 72$ hot private pages $= 88\text{ pages}$) fits inside $N_{\text{dev}} = 96\text{ pages}$. At $K=16$, \texttt{DEMAND\_ELLA} (without prefetching) achieves a $46.84\%$ hit rate ($842$ clean misses), yet achieves a \textbf{lower Stall Ratio ($95.68\%$ vs.\ $116.67\%$)} and higher \texttt{Sim.\ Dev.\ Ops/s} ($102{,}206.74$) than \texttt{DEMAND\_LFU} because sealed-page write-through mirroring eliminates the $3.00\,\mu\text{s}$ dirty-page writeback penalty ($842 \times 9.00\,\mu\text{s} = 7{,}578\,\mu\text{s} < 770 \times 12.00\,\mu\text{s} = 9{,}240\,\mu\text{s}$). Meanwhile, \texttt{SPECULATIVE\_ELLA} pins up to $M_{\text{pre}}(n) \le 4$ admitted lookahead pages per step ($39.39\%$ hit rate, $107.53\%$ Stall Ratio, $96{,}370.88\text{ Sim.\ Dev.\ Ops/s}$). When concurrency reaches $K = 20$, the recurring hot working set expands to $16 + 20 \times 4.7 = 110\text{ pages} > 96\text{ pages}$; because classical LFU suffers from frequency-counter pollution on completed early-turn history pages, its hit rate collapses from $51.39\%$ to $1.21\%$ (and LRU collapses to $0.20\%$). In contrast, ELLA immediately decays completed scratchpad pages via $\exp(-\mu\Delta t_i)$ while pinning $\mathcal{P}_{\text{anchor}}$ and retaining floored $\mathcal{P}_{\text{tool}}/\mathcal{P}_{\text{hist}}$, sustaining a \textbf{28.23\% seed-0 hit rate} ($28.31 \pm 0.38\%$ 5-seed mean) at $K=20$.
    \item \textbf{46.8\% Reduction in Pipeline Stall Ratio:} Across every concurrency level $K \in \{4, \dots, 20\}$, \texttt{SPECULATIVE\_ELLA} achieves the lowest Stall Ratio and highest \texttt{Sim.\ Dev.\ Ops/s} ($+49.3\%$ over LRU at $K=20$), slashing stall overhead at $K=20$ by $46.8\%$ relative ($112.05$ percentage points, from $239.52\%$ to $127.47\%$). By Eq.~\eqref{eq:exact_stall_accounting}, this $11{,}092.0\,\mu\text{s}$ reduction in total stall time ($23{,}712.0\,\mu\text{s} \to 12{,}620.0\,\mu\text{s}$) decomposes transparently into: (a) $555$ fewer total misses saving $555 \times 12.00 = 6{,}660.0\,\mu\text{s}$ ($60.0\%$); (b) sealed-page write-through mirroring eliminating the $3.00\,\mu\text{s}$ dirty writeback penalty across all $1{,}421$ remaining misses, saving $1{,}421 \times 3.00 = 4{,}263.0\,\mu\text{s}$ ($38.4\%$); and (c) partial DMA overlap on the $M_{\text{part}}=26$ in-flight prefetches saving $26 \times (9.00 - 2.50) = 169.0\,\mu\text{s}$ ($1.5\%$).
    \item \textbf{Host Control-Plane Overhead vs.\ Wall-Clock Gain:} While \texttt{SPECULATIVE\_ELLA} strictly dominates on pure device throughput (\texttt{Sim.\ Dev.\ Ops/s}) across all $K$, its host \texttt{Wall Throughput} is slightly lower at $K=4$ and $K=16$ before achieving a $+53.4\%$ gain over LRU ($+55.2\%$ over LFU) at $K=20$. This occurs because $T_{\text{wall}}$ in our Python/NumPy CPU emulator includes host control-plane and priority-queue scan overhead $T_{\text{host\_cp}} \in [1.55, 3.75]\,\mu\text{s}$/access alongside $T_{\text{compute}}^{\text{ideal}} = 5.00\,\mu\text{s}$, an artifact that is amortized in compiled C++/Pallas device kernels where full 64-layer decoding steps execute in $T_{\text{compute}}^{\text{64L}} \approx 160\,\mu\text{s}$ ($0.16\text{ ms}$) with on-device page-table metadata.
    \item \textbf{Component, Static-DAG ($\mathcal{H}_i(t)\equiv 0$), and SOTA Baseline Ablation (Table~\ref{tab:ablation_k20}):} At $K=20$, \texttt{DEMAND\_ELLA} alone lifts 5-seed mean hit rate from $0.22\%$ to $25.30\%$ while retaining $98.12\%$ empirical QK dot-product attention mass, outperforming adapted \texttt{SGLang/RadixAttention}~\cite{zheng2024sglang} ($16.40\%$ hit rate, $71.20\%$ QK attention), \texttt{StreamingLLM}~\cite{xiao2023efficient} ($19.80\%$ hit rate, $74.85\%$ QK attention due to evicting distant tool schemas and history), \texttt{H2O}~\cite{zhang2023h2o} ($22.42\%$), \texttt{Quest}~\cite{tang2024quest} ($23.10\%$), \texttt{CachedAttention}~\cite{gao2024cachedattention} ($23.18\%$), and \texttt{InfiniGen}~\cite{lee2024infinigen} ($24.14\%$). Comparing full \texttt{SPECULATIVE\_ELLA} ($28.31\%$ hit rate, $127.34\%$ Stall Ratio, $98.64\%$ QK attention) against \texttt{STATIC\_DAG\_ELLA} ($\mathcal{H}_i(t)\equiv 0$, KVFlow-style static DAG prefetching~\cite{pan2025kvflow}, $26.41\%$ hit rate, $131.08\%$ Stall Ratio, $96.45\%$ QK attention) isolates the exact contribution of dynamic epistemic branch entropy $\mathcal{H}_i(t)$: $+1.90$ percentage points ($+7.19\%$ relative) in hit rate, $+2.19$ percentage points in empirical QK attention retention, and an additional $3.74$ percentage points ($2.85\%$ relative) reduction in Stall Ratio.

Table~\ref{tab:generalization_sensitivity} evaluates ELLA's generalization across diverse multi-turn workflows and $\pm 50\%$ hyperparameter perturbations at $K=20$: (1) on \textbf{SWE-bench-style repository debugging traces}~\cite{jimenez2024swebench} (12 turns/stream where agents revisit prior-turn reasoning scratchpad blocks with $25\%$ probability during patch verification and test-failure backtracking), \texttt{SPECULATIVE\_ELLA} sustains a \textbf{26.82\% hit rate} (vs.\ $0.45\%$ for LRU and $2.10\%$ for LFU) and \textbf{96.42\%} empirical QK attention retention; (2) on \textbf{Gorilla-style massive API catalog traces}~\cite{patil2024gorilla} (10 turns/stream switching across 32 OpenAPI tool-schema pages), rapid idle-tool decay ($\lambda_{\text{tool}}=0.08$) allows newly predicted tool schemas and DAG-boosted history to preempt dormant schemas within $\approx 8$ steps, achieving a \textbf{29.45\% hit rate}; and (3) across $\pm 50\%$ perturbations to $(\lambda, \lambda_{\text{tool}}, \mu, B_{\text{DAG}})$, hit rate varies by $< 1.2$ percentage points ($27.42\%\text{--}28.62\%$) and Stall Ratio varies by $< 2.3$ percentage points ($126.75\%\text{--}129.02\%$), confirming high robustness without brittle tuning.

\section{Conclusion}
This paper presented Speculative Epistemic KV-Cache Paging (SE-Paging) and the Epistemic Least-Likely-Attended (ELLA) eviction protocol for multi-turn agentic LLM serving. By coupling agent workflow DAG lookahead and conditionally re-normalized action-delimiter epistemic branch entropy to physical memory management, SE-Paging protects attention sinks, tool schemas, and floored history while overlapping DMA transfers with matrix compute in our calibrated $1:32$ physical tensor-buffer emulator and multi-turn trace replays. Future work includes integrating SE-Paging directly with on-device C++/Pallas TPU v6e hardware DMA descriptor rings on full-scale distributed SWE-bench~\cite{jimenez2024swebench} and Gorilla~\cite{patil2024gorilla} production clusters.
